## Domain Language

- **CaciqueAnalytics**: The project. Data pipeline for Chilean football.
- **Primera Chile / Primera Division**: Chilean top-flight league.
- **SofaScore**: Primary data source for 2026 stats. API-based scraping.
- **LanusStats**: Python library wrapping SofaScore/FBRef/etc. Used as fallback.
- **Infographic**: Single image (1080x1080) posted to X. Generated by matplotlib.
- **Gameday / matchday**: A round of fixtures. Chilean league has ~30 per season.
- **ETL**: Extract (scrape SofaScore) -> Transform (clean, compute per90) -> Load (PostgreSQL upsert).
